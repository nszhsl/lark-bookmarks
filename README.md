# 飞书收藏到书签 (lark-bookmarks)

把你在飞书里**发给自己**的链接，自动存进 Chrome 书签，并补上网页标题。

很多人习惯把看到的文章、仓库随手发给自己，当作临时收件箱。这个插件把那些链接定时搬进 Chrome 书签的"收件箱"文件夹，书签会通过 Google 账号同步到你的其他设备。

## 它会做什么

- **定时同步**：每隔一段时间（默认每小时）读取你发给自己的新消息，把里面的链接加进书签的"收件箱"。
- **补标题**：在你的浏览器里打开网页、读出标题，所以知乎这类需要登录才能访问的网站也能拿到标题。
- **保留备注**：链接旁边你写的几个字会跟在标题后面，例如 `某篇文章 | 读书`，搜书签时也能搜到。
- **去重**：同一个链接只加一次；`utm_*`、知乎的 `utm_psn`、公众号的 `scene` 这类分享参数会先去掉。
- **补全旧书签**：可以一键给现有书签里所有"只有网址、没有标题"的条目补上标题。
- **自动分类（可选）**：填上任意兼容 OpenAI 接口的大模型（DeepSeek、通义千问、Ollama 等），新链接拿到标题后会被放进"收件箱"旁边最合适的文件夹；没有合适的文件夹时可以让它新建一个（最多 20 个分类文件夹），所以收藏夹一开始是空的也能用。拿不准的留在收件箱。
- **多台电脑**：设置跟着 Chrome 账号同步，每台电脑各自连接一次飞书。几台电脑同时添加了同一个链接时，插件会自动删掉多余的那份。

## 安装

暂未上架 Chrome 应用商店，先手动加载：

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions`，打开右上角的"开发者模式"。
3. 点击"加载已解压的扩展程序"，选择本仓库目录。
4. 设置页会自动打开，按页面上的步骤操作。

## 设置

插件通过**你自己的飞书应用**读取消息，不经过任何第三方服务器。只需设置一次：

1. 在[飞书开放平台](https://open.feishu.cn/app)创建一个"企业自建应用"。
2. 添加"机器人"能力。飞书读取消息的接口要求应用具备这项能力，插件不会用它发消息。
3. 在"权限管理"的"用户身份"下开通：
   - `offline_access`
   - `im:message.p2p_msg:get_as_user`
   - `im:message:readonly`
   - `im:chat:read`
4. 在"安全设置 → 重定向 URL"中添加插件设置页上显示的地址（形如 `https://<扩展ID>.chromiumapp.org/`）。
5. 创建版本并发布。在公司的飞书里，这一步可能需要管理员审批。
6. 把 App ID 和 App Secret 填进插件设置页，点击"连接飞书"并授权。
7. 在设置页点击"允许读取网页标题"。

Lark 国际版也可以用：在设置页把版本切换为 Lark，并在 [Lark 开放平台](https://open.larksuite.com/app) 创建应用。

## 隐私

- 设置（包括 App Secret 和大模型 API Key）保存在 Chrome 的同步存储里，会随你的 Google 账号同步到你的其他电脑。
- 飞书登录令牌只保存在当前电脑，不同步。
- 插件只读取你和自己的那个单聊，不读其他会话。
- 补标题时，插件会用你的浏览器访问书签里的网址，和你自己打开这些网页一样。
- 开启自动分类时，新书签的标题和网址会发给你填写的大模型服务。
- 插件不包含任何统计或上报代码。

## 开发

```bash
npm install
npm test        # 链接提取的单元测试
npm run e2e     # 在独立的测试浏览器里跑完整流程，飞书接口用模拟数据
```

`npm run e2e` 在一个临时用户目录里启动 Chrome，不会碰你自己的 Chrome 资料。默认使用 Puppeteer 下载的 Chrome for Testing；也可以用已安装的 Chrome，省去下载：

```bash
CHROME_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe" npm run e2e
```

国内下载 Chrome for Testing 较慢时，可以设置 `PUPPETEER_CHROME_DOWNLOAD_BASE_URL=https://cdn.npmmirror.com/binaries/chrome-for-testing`。
